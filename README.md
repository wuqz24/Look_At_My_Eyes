## 本版功能范围

- SC500 系列原厂 720p MIPI → ISP/AWB → DDR → FPGA HDMI 链路。
- RGB、灰度、对比度、颜色掩膜和灰度观察五种画面模式；二值显示阈值为 `112`，当前顶层未接入运动框输出。
- 红、蓝两色两级检测（`rtl/tracker_candidates.v`）：全画面用**一套按实拍纸片标定、且只用与光照无关的饱和度**的颜色门限（红 S≥28 %、蓝 S≥18.75 %，色相 ±45°/±52°，绝对亮度下限只到 V=40/32）做流式 run/连通区域粗定位，下一帧只在这个目标的 ROI 内重新测量，输出目标本体的紧凑包围盒、中心、面积（16 bit）和形状（四角逐格占用：矩形四角满、圆四角空）。面板/掩码显示离十字线最近的候选，云台只跟随红色圆形。
- 状态栏第 11 行是 `HITS Rxxx Bxxx`：上一帧被判为红/蓝的像素数，用来现场判断颜色门限是否过于严格。
- 摄像头画面上仅叠加状态文字、安路标志、色条、**选中目标内部**的稀疏掩膜和中心十字，不绘制不稳定的外接矩形框，也不再给背景上的同色区域上色。
- 双轴 50Hz PWM，脉宽命令以 1/4 µs 为单位、死区 5 px、每帧限速 6 µs；上电归中并执行小角度自检，视频新鲜且识别到稳定目标后才允许跟随，视频故障进入 SAFE；顶到软件脉宽范围时状态栏显示 `LIMIT`。红圆确认沿触发 C12 低有效蜂鸣器一次，使用时打开 SW5。水平 PWM 为 G17，俯仰 PWM 为 R3；外部 ARM 已旁路，E12 不接。
- 舵机 PWM 采用短线 3.3V 直连 MG90S 信号端，不使用 SN74AHCT125N、电阻或电容；独立舵机电源和与 FPGA 共地仍是硬性边界。

识别/掩码/云台的现场问题根因与标定入口见 [识别与云台修复说明](docs/识别与云台修复说明-20261103.md)。

**不是**通用 AI 识别、精确圆形识别、同色多目标身份保持、自动曝光、编码器闭环、360 度无限旋转或严格始终居中的数字裁切系统。上述扩展有设计路线，但没有冒充已完成。

## 作品简介建议稿

定视面向实验教学、固定工位彩色标记跟随和轻量云台演示，采用安路 PH1P35 构建从 MIPI 采集、图像处理到 HDMI 显示的硬件流水线。系统通过颜色分割和稀疏网格包络输出目标位置，在实时视频中叠加框选、坐标与状态，并驱动双轴云台进行有限范围的平滑跟随。随视频帧穿过 DDR 的标签用于观测数字链路延迟及检测画面停滞，以可测量、可解释的实时视觉控制为特色。

该简介描述设计方向，提交比赛前须按实测结果填写帧率、延迟、跟踪范围和稳定性数据。多候选检测是硬件近似的连通区域候选方案，不应表述为 CNN 实例分割；当前仍需 TD 重综合和板级验证。
